# IoT Smart Fan Controller (ระบบควบคุมพัดลมอัจฉริยะ)

โปรเจกต์ฮาร์ดแวร์และซอฟต์แวร์สำหรับควบคุมพัดลมและระบบส่ายอัตโนมัติผ่านอินเทอร์เน็ต (IoT) ทำงานร่วมกับแผงวงจร ESP8266, เซิร์ฟเวอร์ API (Node.js/Vercel) และฐานข้อมูล Supabase เพื่อให้สามารถสั่งการได้จากทุกที่ พร้อมหน้าเว็บควบคุม Dashboard แบบเรียลไทม์

---

## 🏗️ โครงสร้างเทคโนโลยี (Tech Stack)

1. **Hardware (IoT Device):**
   - แผงวงจรควบคุมหลัก: **ESP8266**
   - เซ็นเซอร์ตรวจจับการเคลื่อนไหว: **PIR Sensor** (ต่อที่ขา D5)
   - เซ็นเซอร์วัดอุณหภูมิและความชื้น: **DHT11** (ต่อที่ขา D12)
   - สวิตช์รีเลย์ควบคุม (Relay Module):
     - **พัดลม (Fan):** ต่อที่ขา D1
     - **ระบบส่าย (Swing):** ต่อที่ขา D2 (อ้างอิงโค้ด D2, แต่ตามคอมเมนต์ในโค้ดบางส่วนให้ใช้ D3 สามารถปรับปรุงได้ในอนาคต)
2. **Backend Services:**
   - **Node.js (Serverless API)**: ให้บริการ API Endpoint ผ่านแพลตฟอร์ม Vercel
   - **Database**: **Supabase** (PostgreSQL) สำหรับเก็บสถานะปัจจุบันของอุปกรณ์ (Realtime State)
   - **Authentication**: JWT สำหรับยืนยันตัวตนบน Web Dashboard และ Device Secret สำหรับตัวอุปกรณ์ (ESP8266)
3. **Frontend (Dashboard):**
   - **HTML/CSS/JS (Vanilla)**: สำหรับสร้างหน้าต่าง UI ควบคุมการทำงาน
   - **Tailwind CSS**: จัดการความสวยงามของ Layout และ Component
   - **Font Awesome**: ไอคอน UI ต่างๆ

## ⚙️ รูปแบบการทำงาน (Workflow & Logic)

อุปกรณ์รองรับการทำงานหลัก 2 โหมด ได้แก่ โหมดอัตโนมัติ (Auto Mode) และโหมดสั่งการเอง (Manual Mode):

### 1. โหมดอัตโนมัติ (Auto Mode)
ระบบจะพิจารณาการเปิด-ปิดพัดลมแบบอัตโนมัติตามสภาพภูมิอากาศรอบข้างและการตรวจจับบุคคล:
- พัดลมจะเปิดโดยอัตโนมัติก็ต่อเมื่อ **ตรวจพบการเคลื่อนไหว (หน้าเครื่องมีคนอยู่)** `และ` **อุณหภูมิปัจจุบัน สูงกว่าหรือเท่ากับ อุณหภูมิเป้าหมายที่ตั้งไว้ (Target Temp)**
- หากเปิดอยู่ แล้วไม่มีการเคลื่อนไหวต่อเนื่องเป็นเวลา 2 นาที (120,000 ms - *Fan Off Delay*) พัดลมจะสั่ง **ปิดระบบอัตโนมัติ** เพื่อประหยัดพลังงาน
- **ระบบส่าย (Swing)** สามารถกำหนดให้ทำงานพร้อมกันหากผู้ใช้ส่งคำสั่งให้ส่ายทิ้งไว้ (ระบบส่ายจะหมุนต่อต่อเมื่อพัดลมเปิดอยู่เท่านั้น)

### 2. โหมดสั่งการด้วยตนเอง (Manual Mode)
- ผู้ใช้งานสามารถกดเปลี่ยนโหมดเป็น **"Manual"** ผ่าน Web Dashboard ได้
- เมื่ออยู่ในโหมดนี้ ระบบจะเลิกสนใจเซ็นเซอร์วัดอุณหภูมิและ PIR ทันที
- ผู้ใช้งานเป็นคนกดปุ่ม **[เปิด-ปิดพัดลม]** รวมถึงกดชิด **[ส่าย-หยุดส่าย]** จากหน้าจอโทรศัพท์/คอมพิวเตอร์อย่างอิสระ

## 📡 API Endpoints

ระบบใช้ RESTful API สำหรับการแลกเปลี่ยนข้อมูล:
1. **POST `/api/auth`**: ส่ง `password` (จากผู้ใช้) เพื่อรับ `JWT Token` สำหรับสิทธิ์การใช้งาน
2. **GET `/api/device?id={device_id}`**: ส่งสถานะทั้งหมดให้หน้า Dashboard (ต้องมีแนบ Header Token)
3. **POST `/api/device?id={device_id}`**: คอยรับคำสั่งยิงไปอัปเดตฐานข้อมูล รองรับทั้งจาก:
   - *ฝั่งแอปพลิเคชัน (Web Dashboard)*: ส่งคำสั่งตั้งค่าต่างๆ (Manual, เปิดพัดลม, ปุ่มส่าย, ตั้งอุณหภูมิเป้าหมาย)
   - *ฝั่งฮาร์ดแวร์ (ESP8266)*: ส่งสถานะปัจจุบัน (Temp, Motion) มาเป็น JSON ทุกๆ 2 วินาที

## 🚀 การติดตั้งและนำไปใช้งาน (Deployment & Setup)

### ส่วนที่ 1: การตั้งค่า Backend และ Database (Supabase & Vercel)
1. สร้าง Table บน Supabase โดยเปิด **SQL Editor** แล้วรันไฟล์ `supabase-setup.sql` ที่อยู่ในโปรเจกต์ (สร้างตาราง `fan_state` พร้อม Row สำหรับอุปกรณ์ 2 ตัว และตั้ง RLS ให้เรียบร้อย)
2. คัดลอกและสร้างไฟล์ `.env` ขึ้นมาจาก `.env.example`
3. ตั้งค่าสภาพแวดล้อม (Environment Variables) เช่น:
   ```env
   SUPABASE_URL=...
   SUPABASE_SERVICE_ROLE_KEY=...
   ACCESS_PASSWORD=...
   JWT_SECRET=...
   DEVICE_SECRET_1=...
   ```
   *(หมายเหตุ: ต้องตรงกับ `deviceSecret` ในโค้ด ESP8266)*
4. แนะนำให้ Deploy ขึ้น **Vercel** เพื่อความเรียบง่าย โดยเลือก Framwork Preset เป็น `Other` ระบบจะใช้งานโฟลเดอร์ `api/` และ `public/` โดยอัตโนมัติ

### ส่วนที่ 2: ฮาร์ดแวร์ ESP8266 (Arduino IDE)
1. เปิดไฟล์ `public/esp8266-1.ino` (หรือ 2) ใน Arduino IDE
2. ติดตั้ง Library ภายนอกที่จำเป็น: 
   - `ESP8266WiFi`, `ESP8266HTTPClient`, `WiFiClientSecure`
   - `ArduinoJson` (v6+) สำหรับรับส่งข้อมูล HTTP REST API
   - `DHT sensor library` โดย Adafruit สำหรับคำนวณเซ็นเซอร์ DHT
3. เปลี่ยนข้อมูลภายในโค้ด ได้แก่:
   - `ssid` และ `password`: รหัสผ่านของ Wi-Fi เราเตอร์ส่วนตัวที่จะเชื่อมต่อ
   - `apiUrl`: ลิงก์ Deployment จากข้อที่ 1 เช่น `https://your-vercel.vercel.app/api/device?id=1`
   - `deviceSecret`: เลขรหัสผ่านอุปกรณ์ให้ตรงกันกับค่า `DEVICE_SECRET_{id}` ที่ระบุใน Backend บนเซิร์ฟเวอร์
4. ต่อวงจรโดยใส่ขาสัญญาณตามในโค้ด จากนั้นก็แฟลช (Upload) เข้าบอร์ดได้เลย

## 💻 การเข้าใช้งาน Web Dashboard

1. เปิดเบราว์เซอร์แล้วไปที่หน้า URL เว็บไซต์ที่ได้ Deploy เอาไว้ (ระบบจะโหลดไฟล์ `index.html` เริ่มต้น)
2. เมื่อเข้าเว็บไซต์ ระบบจะแสดง Modal แบบ Popup "กรุณาใส่รหัสผ่าน" - ให้กรอกรหัส `ACCESS_PASSWORD` ที่ตั้งไว้ในระบบหลังบ้านเพื่อเปิดล็อก (ล็อกแล้วมีผล 24 ชั่วโมง)
